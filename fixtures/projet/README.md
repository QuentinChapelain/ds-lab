# Le dossier de projet

La base du dossier où l'on joue le parcours sur un site réel (D102) : `npm run projet -- <dossier>` y pose ces fichiers, le skill du clone par un lien et les réglages de Claude Code, comme `npm run jeu` (D75), sans site fictif ni sources.

| Fichier | Rôle |
|---|---|
| `CLAUDE.md` | Ce que l'IA sait du dossier : l'adresse donnée dans le chat, une app locale servie par l'humain, le projet à écrire, comment repartir de zéro |
| `cible.json` | La cible générique : rayons, espacements et tailles de la valise ; le blanc et les échelles communes (neutre, erreur, succès), sans couleur de marque |

Pas d'entrée de marque : l'IA la lit sur le site et l'écrit (`conduire.md`, la marque).
